| 찾을 것 | 어디서 | 왜 필요한지 |

### 2.2 Nemotron / Meterless / VLM

| 찾을 것 | 확인 질문 |
|---------|-----------|
| 엔드포인트·인증 방식 | Bearer? API key header? |
| **멀티모달(이미지) 입력** | Diagnosis만 텍스트면 VLM을 별도 서비스로 둘지 |
| JSON / structured output | Pydantic schema와 1:1 매핑 가능한지 |
| Context·토큰·이미지 크기 제한 | 업로드 전 리사이즈 필요 여부 |
| Latency | 5–10분 루프 안에 3회 루프 가능한지 |
| Diagnosis / Critic / Judge **역할 분리** | 동일 모델 + system prompt vs 별도 호출 |

### 2.3 Zetaris

| 찾을 것 | 확인 질문 |
|---------|-----------|
| 가입·플랜·쿼터 | 해커톤 기간 내 무료 tier |
| Python/Java SDK vs REST | `services/agent/tools` 연동 방식 |
| PostgreSQL / CSV / API federated query | 질병 DB + 기상을 한 레이어에서 조회할지 |
| D1 연동 실패 시 **Plan B** | 로컬 JSON + 직접 KMA HTTP (Zetaris는 P1 데모만) |
